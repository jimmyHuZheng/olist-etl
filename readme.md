# Olist-ETL

基于 Python + MySQL + Power BI 的轻量级电商数据自动化 ETL 与决策系统。负责定时扫描、清洗从 ERP 导出的离散 Excel 报表，
原子入库至 MySQL 数仓，并对接前端业务看板与告警通知。

---

## 目录结构

```text
olist-etl/
├── config/                  # 数据库连接与工作路径配置
├── pipeline/                # 数据清洗策略实现 (BasePipeline / 工厂类)
├── util/                    # 通用工具集 (MySQL / 文件扫描 / 日志 / 钉钉与邮件通知)
├── tools/                    # 业务自动化应用 (如 PMC 补货/调拨计算)
├── entrance.py              # Python 调度主入口
└── run_etl.bat              # Windows 任务计划批处理执行脚本
```

---

## 核心工作流

```
                 ERP 导出文件放置于 income/ 目录
                               │
               Windows 任务计划执行 run_etl.bat
                               │
                       python entrance.py
                               │
                 识别文件名并匹配清洗策略
                               │
         ┌─────────────────────┴─────────────────────┐
         ▼                                           ▼
   【分流 1: 原生备份】                        【分流 2: 规范清洗】
   追加审计元数据                              字段类型强转、异常值过滤、
   写入 ods_* 全文本表                         主键提取与 Upsert 语法拼装
         │                                           │
         └─────────────────────┬─────────────────────┘
                               │
                    【统一数据库事务控制】
                               │
          ┌────────────────────┴────────────────────┐
          ▼ 成功                                    ▼ 失败
    COMMIT 提交事务                           ROLLBACK 全盘回滚
    源文件移动至 archive/                     源文件隔离至 failed/
    调用钉钉/邮件: 发送成功通知                错误日志保存至 fail_log/
                                              调用钉钉/邮件: 发送告警通知
                               │
                               ▼
                    Power BI 看板数据联动刷新
```

## 自动化定时调度与告警部署

项目通过 Windows 自带的 **任务计划程序 (Task Scheduler)** 配合根目录下的 `run_etl.bat` 实现无人值守自动运行：

### 1. 配置告警通知
在 `config/conf.py` 中填入你的数据库信息，钉钉 Webhook Token 或 SMTP 邮件发送配置：
* **执行成功**：向工作群或管理邮箱推送批次处理概览（处理文件数、耗时）。
* **执行失败**：向工作群推送 `@所有人` 告警，并把报错信息和 `fail_log/` 下的失败日志详情直接随消息发送。

### 2. 设置 Windows 任务计划程序
1. 按 `Win + R` 键，输入 `taskschd.msc` 打开**任务计划程序**。
2. 点击右侧 **创建任务**：
   * **常规**：设置任务名称为 `Olist-ETL-Job`，勾选“不管用户是否登录都要运行”。
   * **触发器**：新建触发器，设定执行频次（例如：每天早上 08:30 执行一次）。
   * **操作**：
     * 操作选择：**启动程序**
     * 程序或脚本：浏览选择项目根目录下的 `run_etl.bat`
     * **起始于（可选）**：**务必填入项目的绝对路径**（例如：`D:\projects\olist-etl`），以确保相对路径正确寻址。
3. 保存后，即可在设定时间全自动跑通全流程。手动测试可右键该任务点击“运行”。
